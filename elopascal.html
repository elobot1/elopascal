Install EloPascal on your device

          
Install EloPascal from a website served over HTTPS. On a computer, localhost can also be used for testing. Opening this page directly from a file does not support installation.

        

        
      

      
    
        
  • Android: Open the website in Chrome, tap the menu (⋮), then choose “Install app” or “Add to Home screen.”
    • 
        
  • iPhone or iPad: Open the website in Safari, tap “Share,” then choose “Add to Home Screen.”
    • 
        
  • Computer: Open the website in Chrome or Edge, then choose “Install EloPascal” from the browser menu.
    • 
      

      
To install EloPascal on a phone, the site must be published over HTTPS. The addresses localhost and 127.0.0.1 refer only to the device running the local server.
